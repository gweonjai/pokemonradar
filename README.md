# Pokemon Radar (포켓몬 GO 약점 & 레이드 카운터) `v0.1.1`

포켓몬 GO를 즐기는 트레이너(아이와 부모)가 레이드 배틀 중 상대 포켓몬의 약점을 즉시 파악하고 최적의 공격 포켓몬을 선출할 수 있도록 돕는 모바일 최적화 웹 애플리케이션입니다.

---

## ⚡ 주요 핵심 기능

1. **실시간 한글 & 초성 검색 (자동완성)**
   - 한글 명칭(예: `피카`, `리자`), 초성(예: `ㅍㅋ`, `ㄹㅈㅁ`), 도감 번호(`006`, `25`), 영문명 검색 지원
   - 검색 결과 드롭다운에서 포켓몬 공식 썸네일, 도감 번호, 타입 뱃지 즉시 확인
2. **포켓몬 GO 전용 정밀 상성 계산기 (방어 기준 데미지 배율)**
   - **치명적 약점 (2.56배)**: 이중 타입으로 인해 약점이 중첩된 최우선 공략 타입 (붉은색/경고 강조)
   - **일반 약점 (1.6배)**: 효과가 굉장한 일반 약점 타입 (주황색/주의 표시)
   - **저항 & 반감 (0.625배 / 0.39배 이하)**: 데미지가 대폭 감소하므로 피해야 할 비추천 타입
3. **포켓몬 GO 인게임 보관함 검색 꿀팁 배너**
   - 포켓몬 GO 앱 보관함 검색창에 즉시 붙여넣을 수 있는 `@타입명` (예: `@바위`, `@물`) 명령어 원클릭 복사
   - 콤마(`,`)로 묶인 전체 약점 통합 검색어(예: `@바위,@물,@전기`) 원클릭 클립보드 복사 지원
4. **18개 포켓몬 공식 타입 컬러 테마 & 팔레트**
   - 노말, 불꽃, 물, 풀, 전기, 얼음, 격투, 독, 땅, 비행, 에스퍼, 벌레, 바위, 고스트, 드래곤, 악, 강철, 페어리 공식 색상 팔레트 완벽 준수
   - 18개 타입 팔레트 한눈에 보기 팝업 제공
5. **포켓몬 GO 사용 가능 기술 (노말 어택 & 스페셜 어택)**
   - 각 포켓몬의 빠른 공격(Fast Move) 및 특수 필살기(Charged Move) 목록 제공
   - 기술별 속성 타입 뱃지 및 특별한 레거시/커뮤니티 데이 전용기 태그 표기
6. **모바일 최적화 UI/UX**
   - 스마트폰 화면(`max-w-md` 가운데 정렬)에 최적화된 모바일 퍼스트 레이아웃
   - 아이들과 부모도 쉽게 알아볼 수 있는 큼직하고 직관적인 카드 UI 구성

---

## 🛠 기술 스택

- **Framework**: Vite + React 19 + TypeScript
- **Styling**: Tailwind CSS v4, Lucide React
- **Data Source**: PokeAPI 공식 일러스트(Official Artwork) + 1~9세대 기본 내장 데이터셋 및 동적 캐싱
